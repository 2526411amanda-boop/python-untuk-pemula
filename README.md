# Python untuk Pemula

Praktikum Python dasar dari Santrikoding (Materi 02, Pemrograman Web).

## Materi yang Dipelajari

1. Pengenalan & Instalasi Python
2. Variabel dan Tipe Data
3. Operator pada Python
4. Kondisi If Else
5. Perulangan (for dan while)
6. Lists dan Dictionaries
7. Function
8. Class dan Object
9. PIP dan Virtual Environments
10. Konfigurasi Environment/IDE
11. README.md dan requirements.txt

## Cara Menjalankan

```bash
git clone https://github.com/2526411amanda-boop/python-untuk-pemula.git
cd python-untuk-pemula
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python latihan.py
```

## Struktur Folder

- `latihan.py`: kode latihan semua bab
- `screenshots/`: bukti hasil eksekusi program
- `requirements.txt`: daftar library
- `.vscode/`: konfigurasi VS Code
