## Cara Menjalankan

```bash
git clone https://github.com/2526411amanda-boop/python-untuk-pemula.git
cd python-untuk-pemula
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python latihan.py
python python-dasar.py
```
